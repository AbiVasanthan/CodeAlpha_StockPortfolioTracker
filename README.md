CodeAlpha_StockPortfolioTracker

A simple phone shop stock tracker made with Python.

About
The user enters phone brands and quantities. The program uses a hardcoded dictionary of prices, calculates the value of each brand and the total stock value, and saves the result in a text file.

Features
- Fixed price list stored in a dictionary
- User enters brand names and quantities
- Handles wrong input (unknown brand, letters instead of numbers, zero or negative numbers)
- Adds up quantities if the same brand is entered twice
- Shows a summary with the total stock value
- Saves the report to `phone_stock.txt`

Concepts used
- Dictionaries
- `while` loop and `for` loop
- `try / except` for error handling
- Input and output
- Basic arithmetic
- File handling
